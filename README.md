
# AI-Powered Healthcare Mobile App
### Product Design | Healthcare UX/UI | AI Integration

A user-centered healthcare mobile application designed to simplify access to medical information, AI-assisted consultations, and doctor appointments.

**Role:** Lead UX/UI Designer & Project Manager

**Industry:** Digital Health / Healthcare Technology

**Platform:** Mobile App — iOS & Android

**Tools:** Figma, UX Research, AI Prototyping, Design Systems

---

## Project Overview

The goal was to design an intuitive healthcare experience that connects patients with medical information, AI-assisted guidance, and healthcare providers.

The project focuses on reducing friction in healthcare navigation, improving usability, and making complex medical workflows more accessible.

## The Challenge

Patients often face difficulties when navigating digital healthcare services:

- Complex medical information
- Confusing appointment booking processes
- Fragmented healthcare experiences
- Unclear navigation and user journeys
- Limited access to timely guidance

The design challenge was to simplify these workflows without compromising user trust or clarity.

## UX/UI Solution

### 01. AI-Assisted Consultation

Designed an intuitive conversational interface that helps users describe symptoms and receive AI-assisted guidance.

The experience emphasizes clear information hierarchy, understandable interactions, and user control.

### 02. Doctor Discovery & Booking

Created a streamlined appointment booking experience to help patients find healthcare providers and schedule visits with fewer steps.

### 03. Patient Dashboard

Designed a centralized mobile interface for accessing healthcare information, appointments, and post-care activities.

### 04. Onboarding & Subscription UX

Structured user onboarding and subscription-related interactions to improve clarity and guide patients through the application.

## Design Process

**Discovery → UX Research → User Flows → Wireframes → UI Design → Interactive Prototype → Developer Handoff**

The design approach focused on:

- User-centered navigation
- Clear visual hierarchy
- Accessible mobile UI patterns
- Consistent interaction design
- Scalable interface components

## Deliverables

- UX Research
- User Flows & Wireframes
- Mobile UI Design
- Interactive Figma Prototype
- Design System
- Developer Handoff

## Project Outcomes

The design aimed to improve patient engagement, simplify appointment booking, and reduce friction in healthcare support workflows.

The Upwork portfolio reports improvements in retention and support requests. These metrics should be presented as verified outcomes only when supporting analytics and measurement details are available.

---

## Design Philosophy

**Complex Healthcare Workflows. Simple Patient Experiences.**

The objective is to make digital healthcare more accessible, understandable, and intuitive through thoughtful product design.
